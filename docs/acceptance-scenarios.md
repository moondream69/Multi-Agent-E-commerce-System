# 重构验收场景清单

> 本清单是推翻式重写的验收基线(ADR-0005):继承场景=旧系统已验收功能,新系统须「场景等价 + 新架构」通过;新增场景=新机制。全部通过 → 部署演练环境 → 真实数据导入(CSV)→ 小范围试运行 → 生产切换(访谈 Q6)。

## A. 继承场景(旧系统已验收,须等价通过)

| # | 场景 | 验收标准 |
|---|---|---|
| A1 | 登录/退出 | JWT 认证、平权无角色、未认证拒连 |
| A2 | 多会话 | 新建/切换/删除/重命名、登录新开、刷新恢复(localStorage)、标题截断 20 字、空白会话惰性落库、切会话可见历史消息(消息流读端点) |
| A3 | 选品分析流程 | trend_query → competitor_analysis → scoring → generate_report 四步走通,报告含评分等级;**报告有检索依据**(情报语料非空;ADR-0007) |
| A4 | 报告→自动商品草稿 | 选品 Agent 在 `generate_report` 之后调 `draft_create` 落 draft(工具化,非事件触发);字段由 LLM 从报告结论提炼,工具必填校验(sku/title/price/category) |
| A5 | 商品管理 | 创建/按类目查询/按 SKU 查询/状态更新;上架进审批(切片断点) |
| A6 | 订单管理 | 创建/流转/按状态查询/列表查询;非法流转拒绝(7 态状态机) |
| A7 | 库存检查 | 五档告警文案;数据源 = products.stock 真实字段(不再是 LLM 自报) |
| A8 | 订单状态变更→主动通知 | 状态映射表生成通知文案(零 LLM 成本),WS 推送 |
| A9 | 库存告警→通知铃铛 | `notification.created` 事件入铃铛,面板内按 kind 分组,未读徽标累计(0 隐藏、99+ 封顶) |
| A10 | 客服基础能力 | translate/faq_search/order_lookup/manage_template 全部可用;**FAQ 检索有据**(FAQ 语料非空;ADR-0007) |
| A11 | 升级工单 | escalate_ticket 落表 + 界面可见列表与结单动作(实体化后语义增强) |
| A12 | 审批决定审计 | 决定人/决定时间/备注全量落库 |
| A13 | 事件流实况墙 | 全局事件实时展示(语义配色+中文标签),与切片时间线分工共存 |
| A14 | 铃铛未读持久化(升级:服务端按用户已读) | 通知落库按用户扇出;开面板幂等清零;每组最近 50 条服务端截断;多端未读一致(notification.read poke → 凭 token 重拉) |
| A15 | 影子模式 | 演练环境:高危建议以 shadow 落表,一键补执行 |
| A16 | Agent 消息 Markdown 渲染(升级:渲染面扩展) | Agent 回复按 Markdown 渲染(标题/列表等富文本),**用户消息仍纯文本**,原始 HTML 不透传(无 XSS 面);渲染面由旧系统的「驾驶舱会话消息流」**扩展至起草工作台草稿 + 审批中心执行报告 + 驾驶舱切片答案**(#52 补,通用面);ADR-0007 |

## B. 新增场景(新机制)

| # | 场景 | 验收标准 |
|---|---|---|
| B1 | Manager 规划分派 | 简单需求直达业务 Agent;复杂需求拆切片并声明依赖(规划轨迹前端可见) |
| B2 | 切片执行全流程 | 段1 完成 → interrupt 挂起 → 审批单(批内打包)→ 审批通过 → 用户指令(按钮或自然消息)→ 段2 → … → 完成;期间系统不空转(执行释放) |
| B3 | 切片被拒→重规划 | Manager 携拒绝原因重规划(跳过/替代路径/终止),前端显示重规划事件 |
| B4 | 批量审批打包 | 同类型动作批内同进同退,一次人工决定;不跨类型混批 |
| B5 | durable 恢复 | 切片挂起时重启服务,resume 后从断点继续,不重放已完成段 |
| B6 | 动态工具暴露 | 未授权工具对 LLM 不可见;图级边约束拒绝非法迁移 |
| B7 | 三层风险分类 | 免审动作直行(draft 编辑)、审批动作全进护栏(上架/下架/改价/删除/流转/取消)、禁做工具不存在 |
| B8 | CSV 批量导入 | 商品/订单/买家批量导入,重复/冲突可处理,幂等语义(买家先于订单) |
| B9 | 真实库存扣减 | REST 下单扣减 stock,库存检查读库,负数防护 |
| B10 | 汇率快照 | 订单落库记录汇率快照(基准 CNY,Redis 缓存 4h);汇率 API 与缓存双失效时**留空落库** + `fx_missing` 通知(人工核对),不拒单;REST 下单与 `order.create` apply 两路同语义 |
| B11 | 起草工作台 | 贴买家消息 → 查证证据展示(FAQ/订单/商品指代三类;#39 补商品)→ AI 多语草稿 → 人工编辑 → 一键复制 |
| B12 | 查证优先硬约束 | 客服未调 faq_search/order_lookup/product_lookup 不出草稿(图级拒绝,非提示词);商品查证 #38 |
| B13 | Manager fallback | Manager LLM 失败/超时 → 关键词规则确定性路由兜底 |
| B14 | Langfuse 全链路 | Manager 规划/子图/工具/审批决定 trace 可见,与审计互链 |
| B15 | 影子环境自适应 | 演练环境审批中心显示影子段,生产环境隐藏(含补执行端点 prod 拒绝;#37) |
| B16 | 会话记忆 | 短上下文+摘要:最近 6 条消息(≈3 轮往返),消息数 > 12 条触发 LLM 摘要;多轮连续对话语义连贯 |
| B17 | 步数上限 | 业务 Agent 超 10 步/Manager 超 5 步强制终止,产出「未完成+原因」 |
| B18 | 并发冲突防护 | 两任务并发动同一商品,DB 事务+审批护栏兜底,无脏写 |
| B19 | 起草工作台多语言 | 中/英/日/德/法买家消息均出对应语言草稿 |
| B20 | 失败语义分层收敛 | 子图 LLM 失败 → 切片如实「未完成+原因」,任务行 `failed` + `task.failed` 广播,端点如实返回;编程错误兜底收敛后仍上抛 500,无悬挂 `in_progress` |
| B21 | 报表聚合 | 驾驶舱经营快照:订单状态分布、近 7 日成交额(CNY 快照口径,缺汇率单列待核)、低库存商品(与告警同谓词)、未结工单数;纯 SQL 零 LLM |
| B22 | 通知落库与多端同步 | 通知信封按用户扇出落库(迁移 0005);GET /api/notifications 返回每组最近 50 条 + 全量未读计数;POST read 幂等清零并提交后广播 poke;关页期间产生的通知重开后可见;落库失败仅日志,不影响业务与广播 |
| B23 | 协作管线实时轨迹 | 规划完成/切片分派/切片终态实时广播(`task.planned` / `slice.started` / `slice.completed`);驾驶舱协作管线展示 Manager 与三业务 Agent 实时状态与切片归属;断点挂起期间切片显「等待审批」不误标完成;失败/拒绝如实归位;durable 重放不重复广播分派 |
| B24 | 数据台(只读视图) | 商品/订单只读列表(无任何写操作,对外状态变更仍走对话 + 审批);行级「问 Agent」跳转驾驶舱并预填 Manager 输入(不代发);数据源为只读端点(订单列表端点新增);ADR-0006 |
| B25 | 汇率卡片 | 驾驶舱汇率卡片:当期汇率(基准 CNY)+ 近 N 日走势 + 缓存时刻;fx_missing 显「待核」;走势数据源 spec 定(优先外部 API 时序,兜底订单快照时序点);ADR-0006 |
| B26 | 生产形态(同源托管) | 前端构建产物随 app 镜像同源托管于单端口 3000:浏览器直开 `http://<主机>:3000` 出登录页并走通核心链路(`/api` 与 `/socket.io` 未被静态面遮蔽、实时通道握手通过);以局域网 IP 访问同样可用(须在 `CORS_ORIGINS` 列出);无 dist 时根路径如实 404(纯后端部署与离线套件不回归);issue #36 |
| B27 | 知识库语料与统一检索 | `faq` / `market_intel` 两集合非空,切块带**完整溯源**(文档标识/标题/来源渠道/发布日期/章节或页码/切块序号);客服域可经统一检索工具一次查两集合;现有 `faq_search`/`trend_query`/`competitor_analysis` 行为不回归;语料重灌**幂等**(同文档覆盖、不产生重复行)并留版本台账;ADR-0007 |
| B28 | 答案引用小点 | 检索类答案带**切块级引用小点**(上标数字,同一文档多次引用合并编号);点开显示被引切块原文与完整溯源;引用数据**随回答一起下发**(前端自足、无需二次请求);无检索依据的产出(评分/情感/翻译)不标引用;**不做图级硬约束**,格式合规由评测暴露;ADR-0007 |
| B29 | Agent 评测跑批(最小评测面) | 离线评测 CLI 跑通选品金标场景:产出快照落盘(含语料版本指纹),judge 分数与任务 trace / dataset run 互链(Langfuse);**机械防伪引**可判(残留未解析标记 = 疑似伪造);换 rubric / 换 judge **不重跑任务**(run/score 解耦);跑批走专用净库、不触演示素材;#45 定格 + ADR-0008 |
| B30 | 评测判据可判 + 产出非空不静默(评测驱动质量线) | ①判分材料补齐:判分提示词渲染**被引切块正文**(编号 → 切块标识 → 正文;超长显式标注截断),判据「结论性陈述有查证证据支撑」由**不可判**转为可判——以现批快照(`run-20260916T065030Z`)重评为证,客服线 4 条假阴性归零;②动作类陈述(工单/草稿/审批)非「查证证据」,判分提示词明示边界;③**产出为空不得静默通过**:作答轮正文为空(全文落 `reasoning_content`)即同预算重试一次,仍空记「未完成(正文为空)」→ 任务行 `failed`(B20 同口径)→ 跑批器**显式报错**,不落 null 快照;④快照三态可辨(「没执行 / 空产出 / 未完成」:`executed` 如实、`incomplete` 落盘);⑤**情报不足契约**:检索零命中时选品线不得执行 scoring / generate_report / draft_create,如实上报情报缺口(缺哪些维度、需补什么数据源)——「诚实不被扣分」靠**金标场景不落进零命中**来兑现(品类须在语料有可检索面),判据真源不动;⑥切片执行段收到**原始用户请求 + 本切片职责**两段(规划描述缺主语时产出不跑偏);issue #64 |

## C. 验收执行

- **自动化**:契约测试(前端事件契约)、图结构测试(工具暴露/边约束/切分)、审批状态机测试、CSV 导入幂等测试。
- **手工走查**:切片交互(挂起/审批/指令驱动)、起草台双栏、审批中心切片式审批单、事件流+时间线共存、生产形态(单端口 3000 从头走一遍:登录 → 四视图 → 实时通道)。
- **里程碑**:清单全绿 → 演练环境部署(影子模式)→ 真实数据 CSV 导入 → 小范围试运行 → 生产切换。
